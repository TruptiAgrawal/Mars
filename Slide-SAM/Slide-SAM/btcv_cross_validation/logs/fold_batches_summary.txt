WHY BATCH COUNTS DIFFER ACROSS FOLDS
--------------------------------------
Each fold holds out a different set of 6 subjects for testing.
The remaining 24 subjects form the training set.
Since CT volumes vary in number of axial slices, each fold's
training set has a different total slice count → different batches/epoch.
The dataloader samples each slice ~2.6x per epoch (random crop augmentation),
so: batches/epoch ≈ total_training_slices × 2.64 / batch_size(4)

NOTE ON CROSS-FOLD COMPARISON
--------------------------------------
Because batch counts differ, comparing fold performance at the same
EPOCH number is not strictly fair. Prefer comparing at the same
ITERATION number (e.g. iteration 35000) using the iteration checkpoints
saved every 5000 iterations. These are consistent across all folds
regardless of epoch/batch differences.

fold1 and fold2 have nearly identical batch counts (1904) by coincidence —
their respective held-out sets happen to contain volumes with similar
total slice counts.
